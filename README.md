# Fuo Drive ☁️

一个属于我和朋友们的私人小网盘。

## 这是什么？

这是一个简单的网页版网盘，用来存我们自己的小文件，比如：
- 作业和笔记
- 喜欢的图片
- 代码片段
- 各种小文档

## 怎么用？

打开网页后，你可以：
- 📤 **上传文件**：把你想存的文件传上来
- 📥 **下载文件**：把存好的文件下载到自己的电脑
- 📁 **浏览文件**：看看都存了些什么

## 注意事项

- 单个文件不能超过 **100MB**
- 存太多大文件会用完空间哦
- 这是我们自己的小地盘，别告诉太多人呀～
